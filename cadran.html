TROIS SOUS‑CADRANS RÉINTERPRÉTÉS

Structurer · Relier · Transformer.

Les trois sous-cadrans du v7.1 répétaient tous les mêmes heures/minutes/secondes civiles. Dans cette édition, ils deviennent trois lectures fonctionnelles distinctes du même instant HVU.

🔵 STRUCTURER
Heure HVU —

Couche macro : position parmi les 11 heures. Correspondance symbolique HVU : bleu / cryogénique / intelligence, sans revendication physique automatique.

🟢 RELIER
Unité —

Couche relationnelle : position parmi les 33 unités de l’heure. Correspondance symbolique : vert / électromagnétique / vie.

🔴 TRANSFORMER
Pas —

Couche micro : position parmi les 33 pas de l’unité. Correspondance symbolique : rouge / thermique / émotions.

function arcPath(cx,cy,r1,r2,a0,a1){
  const large=(a1-a0)>Math.PI?1:0;
  const x1=cx+r1*Math.cos(a0), y1=cy+r1*Math.sin(a0);
  const x2=cx+r2*Math.cos(a0), y2=cy+r2*Math.sin(a0);
  const x3=cx+r2*Math.cos(a1), y3=cy+r2*Math.sin(a1);
  const x4=cx+r1*Math.cos(a1), y4=cy+r1*Math.sin(a1);
  return `M ${x1} ${y1} L ${x2} ${y2} A ${r2} ${r2} 0 ${large} 1 ${x3} ${y3} L ${x4} ${y4} A ${r1} ${r1} 0 ${large} 0 ${x1} ${y1} Z`;
}

function drawSubDial(rootId, color){

  document.getElementById(rootId.id+'_S').setAttribute('d', pathFor(40, s%60, 60));
}
