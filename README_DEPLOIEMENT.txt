CONTENU
Les cinq modules, les 42 images, les données et les trois archives historiques du paquet fourni sont conservés. Les images ne sont ni recompressées ni redimensionnées.
Les archives sont chargées à la demande et restituées à l’identique. Les images communes sont partagées entre les archives et le site. La taille et le SHA-256 de chaque archive reconstruite sont contrôlés.

CLOUDFLARE PAGES
Déposer ce ZIP entier en Direct Upload, avec index.html à la racine. Aucun build n’est nécessaire. Ce paquet est destiné à un hébergement statique HTTPS.

GITHUB PAGES
Décompresser puis déposer l’arborescence entière dans le dépôt. Activer ensuite GitHub Pages sur la branche et le dossier appropriés : déposer les fichiers seul ne publie pas le site.

IPHONE
Ouvrir l’adresse publiée dans Safari, puis Partager > Ajouter à l’écran d’accueil. Dans le Hub, toucher Précharger toute l’application hors ligne. Attendre la confirmation sans erreur. Les archives font partie du préchargement. La génération IA nécessite toujours un Bridge HTTPS configuré et une connexion.
